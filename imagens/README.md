Os retratos abaixo são exibidos de forma circular na seção de contato. O
enquadramento é definido no CSS para preservar os arquivos originais.

| Arquivo | Pessoa |
|---|---|
| `paula.jpeg` | Paula Amaral |
| `mellynda.jpeg` | Mellynda de Jesus |
| `malcher.jpeg` | Paulo Malcher |
| `larissa.jpeg` | Larissa Luz |

O recorte redondo é feito pelo CSS. Os arquivos originais não devem ser
substituídos por versões recortadas.
